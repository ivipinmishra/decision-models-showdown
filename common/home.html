A side-by-side experiment

Two decision-model APIs.
Same questions. Side by side.

OpenAI Decisions (gpt-6-luna) and TypeSafe Jev both answer typed questions (yes/no, pick one, rate on a scale) with probabilities instead of prose. This demo sends identical questions to both in parallel. Plain code then makes the final call, using thresholds you control.

How every run works

  1. Inputticket text or alert JSON
  2. Same typed questionschoice · yes/no · score
  3. Both APIs, in parallelOpenAI and TypeSafe
  4. Normalized answersprobabilities + confidence
  5. Your code decidesthresholds, not model text

Read this before drawing conclusions

  • MOCK mode is random. A provider without an API key returns hash-derived fake probabilities. Its numbers say nothing about the model.
  • Validate vendor claims on your own data. Latency depends on your region and network, and calibration depends on your domain.
  • A confident answer can still be wrong. Confidence describes how concentrated the distribution is, not whether the answer is correct.
  • To measure on the labeled samples, run python eval.py --app tickets or --app alerts.
